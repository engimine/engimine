# Sentinel-2 desde cero en Python

Manual practico en espanol para aprender a trabajar con datos Sentinel-2 directamente desde Python, sin depender de Earth Engine ni de plataformas cerradas.

La serie se publicara por capitulos.

## Capitulos

- [Capitulo 0 - Preparar el terreno: entender Sentinel-2 y dejar Python listo](./capitulo-00/README.md)
- [Capitulo 1 - Rasters y datos Sentinel-2 reales](./capitulo-01/README.md)
- [Capitulo 2 - Indices espectrales: NDVI, NDWI y NDBI](./capitulo-02/README.md)
- [Capitulo 3 - Dimension temporal: composiciones, cubos de datos, cambio e informe tecnico](./capitulo-03/README.md)
- [Capitulo 4 - Espacio verde por habitante: Sentinel-2 + barrios + H3 + GHSL](./capitulo-04/README.md)
- Capitulo 5 - Clasificacion de usos del suelo (proximamente)

## Objetivo

Construir desde cero un flujo reutilizable para buscar, descargar, procesar, analizar y clasificar datos Sentinel-2 con Python, generando productos GIS, estadisticas e informes tecnicos reproducibles.
